# Quarto clean theme demo (archived)

**This repo is no longer maintained.** The demo now lives in the
[`demo/`](https://github.com/grantmcdermott/quarto-revealjs-clean/tree/main/demo)
folder of the main
[**clean** Quarto Revealjs theme](https://github.com/grantmcdermott/quarto-revealjs-clean)
repo, where it is kept in sync with the theme automatically.

- Live demo: https://grantmcdermott.com/quarto-revealjs-clean/demo.html
- Use the demo as a template:

```sh
quarto use template grantmcdermott/quarto-revealjs-clean/demo
```
